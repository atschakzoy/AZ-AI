# AI-102 — Designing and Implementing a Microsoft Azure AI Solution

> **Goal:** Build, deploy, and manage production AI solutions on Azure using Microsoft Foundry, Foundry Tools, and the Azure AI SDKs. Write Python code that calls vision, language, speech, document intelligence, knowledge mining, and generative AI services — then deploy securely to Azure.

---

## What is AI-102?

AI-102 is Microsoft's **AI Engineer certification** (updated December 23, 2025). It tests whether you can build real AI solutions on Azure — calling Foundry Tools APIs from Python, building RAG pipelines, creating AI agents with Microsoft Foundry Agent Service, and deploying AI applications to production.

## How to use these stages

1. **Go in order** — Stage 01 sets up everything else
2. **Write the code** — every stage has working Python examples, run them
3. **Do the exercises** — reading without building is not enough for this exam
4. **Read the exam checklist** at the end of each stage

## What you will be able to do after these 8 stages

- Provision and secure Foundry resources using Managed Identity, Private Endpoints, and network rules
- Moderate harmful content with Azure Content Safety and Prompt Shields
- Build image analysis, OCR, face detection, and custom vision apps
- Perform text analytics, translation, NER, and sentiment analysis
- Transcribe and synthesise speech
- Extract structured data from documents and forms
- Build a semantic and vector search engine with Azure AI Search
- Call Azure OpenAI in Foundry, engineer prompts, and use function calling
- Build a RAG pipeline that answers questions from your own documents
- Build multi-step AI agents with the Foundry Agent Service
